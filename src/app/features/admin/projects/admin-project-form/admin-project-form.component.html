Identidad

El slug es la parte final de la URL de la ficha. Si lo cambias en un proyecto ya publicado, el enlace antiguo deja de funcionar.

Descripciones

Una o dos frases. Es lo único que se ve sin abrir la ficha.

Listas

Una entrada por línea. No se separan por comas a propósito: el contenido lleva comas y partir por ellas convertía una viñeta en tres.

Enlaces

La ficha muestra el despliegue si existe y, si no, la descarga. Para una release de GitHub conviene apuntar a /releases/latest y no al .exe de una versión concreta: así no hay que volver aquí cada vez que publiques una nueva.

Arquitectura

Resúmenes de una línea que se muestran en la ficha.

Readme

Las cinco secciones del caso de estudio.

Desafíos

El diagrama de arquitectura, el stack estructurado y las métricas no se editan aquí: se escriben en src/assets/data/projects.json y se suben con pnpm run mirror:push. Guardar desde este formulario no los altera.
