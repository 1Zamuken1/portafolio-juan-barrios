Sobre mí

Soy Tecnólogo en Análisis y Desarrollo de Software del SENA, orientado al desarrollo de aplicaciones web y soluciones de software mantenibles.

Mi principal enfoque está en Java y Spring Boot, especialmente en el desarrollo de APIs REST, lógica de negocio, persistencia de datos y diseño de aplicaciones con responsabilidades bien separadas.

También cuento con experiencia desarrollando interfaces con Angular, aplicaciones con Python y Django, automatizaciones e integraciones con herramientas de IA, además de trabajar con bases de datos, Docker y control de versiones.

Actualmente desarrollo software en un entorno orientado a ciberseguridad y MDR, donde participo en el análisis de plataformas, contenedores y soluciones utilizadas por el equipo.

Me interesa especialmente entender cómo funciona una solución de extremo a extremo, identificar oportunidades de mejora y construir software que sea fácil de mantener y evolucionar.
